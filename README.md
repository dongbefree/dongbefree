我认可的做法
- 先跑通再谈完美——最小闭环优先，丑没关系。
- 砍掉比添加更值钱——页后没有后台、没有标签体系，只留「投入—消化—次日回顾」这一个闭环。
- 诚实面对限制——每个项目 README 里都有一节「已知限制」，写清楚它现在做不了什么。
- 用 AI 做执行，自己做判断——需求定义、验收、取舍是我做的，实现是 AI 生成后我逐轮改的。
